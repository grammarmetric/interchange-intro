# Interchange Intro — Interactive worksheets

Self-contained HTML worksheets for **Interchange Intro, Fifth Edition**, one
file per unit, each with an **English | 中文** switch. Same shape as the Mindset
IELTS Foundation Unit 5 worksheet, but the second track is Chinese rather than
band 6.

```
index.html          contents page, links every built unit
unit01.html …       one self-contained worksheet per unit — these are the deliverables
_source/            everything needed to rebuild them
```

Open any `unitNN.html` in a browser. Nothing is fetched from the network: every
picture and recording is a base64 data URI inside the file.

**Live:** <https://grammarmetric.github.io/interchange-intro/>

Reachable by link, not by search: `robots.txt` disallows everything and every
page carries `noindex, nofollow, noarchive, nosnippet, noimageindex`. Each unit
is 5–9 MB, so it takes a moment to arrive and then runs entirely offline.

## Layout

```
_source/
  units/unitNN/
    worksheet.html    ← the file you EDIT: readable HTML with two macros
    crops.json        ← measured crop rectangles + watermark guards
    crops/*.png       ← generated by crop.mjs
    source.md         ← generated by extract.mjs: OCR pages + teacher's keys
  audio/unitNN/
    *.mp3             ← imported from the CDs
    tracks.json       ← which track belongs to which exercise
  build.mjs  crop.mjs  verify.mjs  extract.mjs  import-audio.mjs
  make-index.mjs  pngcrop.mjs
```

Every tool takes `--unit N` or `--all`.

## Adding a unit

```bash
node _source/extract.mjs --unit 2      # OCR pages + teacher's answer keys -> source.md
node _source/crop.mjs    --unit 2      # cut the pictures (needs crops.json first)
node _source/build.mjs   --unit 2      # embed everything -> unit02.html
node _source/verify.mjs  --unit 2      # drive a real browser and prove it works
node _source/make-index.mjs            # refresh the contents page
```

The work that is actually *work* is writing `units/unitNN/worksheet.html` and
measuring `crops.json`. Everything around it is now mechanical.

### 1. Read `source.md`

`extract.mjs` puts the raw material in one document per unit:

- **OCR of each Student's Book page.** The full-book PDF has a text layer (the
  per-unit PDFs do not). It is noisy on picture-heavy pages, so it is a
  transcription *aid* — always check it against the rendered page.
- **The teacher's edition notes**, whose text layer is clean. This is the only
  acceptable source for answers. Never deduce a key from the audio.
- **The unit's imported tracks**, with the exercise each belongs to.

### 2. Measure `crops.json`

Rectangles are pixels in a page rendered at 140 dpi (1157 × 1637). Two guards,
both machine-checked by `crop.mjs`:

- **`avoid`** — the pirate watermarks (`www.frenglish.ru`, `irLanguage.com`,
  the Persian stamp). A crop overlapping one is a build error.
- **`patch`** — a watermark sitting *on top of* artwork the exercise needs is
  painted out with the median colour of the ring around it, before cropping.
  Unit 1 needs this once: the Persian stamp is printed across the middle of
  Ex 7 picture 4, and cropping around it would cut the speech bubble.

Keep the speech bubbles. In a worksheet the printed dialogue is the exercise,
not the answer. (The tile crops in `~/bridge` do the opposite, for a game.)

### 3. Write `worksheet.html`

Copy Unit 1's and replace the contents. Two macros:

```
{{IMG:ex01-photo|alt text}}         -> the crop, as a data URI
{{AUDIO:p002-ex01-…mp3|Track 1}}    -> a player block, as a data URI
```

A macro naming an asset that is not on disk fails the build; `build.mjs` also
warns about crops and tracks that no exercise uses.

## The English | 中文 switch

Every level-specific string is paired as `.enonly` / `.zhonly`, and the CSS
that hides them is **the last rule block in the stylesheet** — anything with
its own `display` otherwise leaks through on source order.

The split is not a straight translation, because the two tracks are not two
difficulty levels — one of them is the language being taught:

| | English track | 中文 track |
|---|---|---|
| Rubrics, tips, notes, headings | English | **replaced** by Chinese |
| Dropdown labels naming a concept (*first name*) | English | **replaced**, e.g. 名 first name |
| Dialogue the learner reads aloud | English | English **plus** a Chinese line under each turn |
| Word banks, answer options, grammar boxes | English | English, unchanged |
| Gap-fill conversations | English | English, with a collapsible **中文对照** panel |
| Audio | untouched | untouched |

**The English never disappears.** Swapping the dialogue for Chinese would leave
nothing to learn from.

**Gap-fill conversations get a collapsed panel, not inline translation.** A
translation of *He's in our history class* hands over the He's/She's choice.

Answers are given by dropdown or radio button rather than typing: the learner
reads Chinese and cannot reliably produce Latin letters, and a dropdown tests
the same grammar choice a blank does.

### A trap worth remembering

`<option data-zh="…">` **must carry an explicit `value`**. Swapping innerHTML
for the Chinese label also changes `option.value` when the attribute is absent,
which silently made seven Unit 1 questions unmarkable in Chinese mode. The
Mindset Unit 5 file uses the same `option[data-b6]` pattern and may share the
latent bug.

## Verifying

```bash
node _source/verify.mjs --all
```

Headless Edge or Chrome over the DevTools Protocol, using the WebSocket built
into Node — no npm, no driver library. Nothing is hard-coded per unit; the
expected counts are read out of the page, so a new unit is covered the day it
is written.

- every picture embeds **and decodes**, every recording embeds, nothing points
  at the network
- every marked control is filled with its own answer and the page must score
  100% — this is what catches a `data-a` no option can satisfy
- one answer is then broken on purpose; exactly one mark must be lost
- the whole pass repeats in 中文, which must score 100% from the same key
- every rubric and tip contains Chinese in Chinese mode; every spoken line has
  a translation; every gap-fill conversation has its 中文对照 panel
- answers reach `localStorage`; Clear all empties everything; no console errors

## Audio

```bash
node _source/import-audio.mjs            # all 16 units
```

184 tracks, 160 MB. CD 1 filenames carry unit/page/exercise and parse with one
regex; CD 2 and CD 3 are page-keyed only (`p36-1.mp3`, and the split variant
`p37-4A.mp3`), so those go through a page → unit map. One CD 1 track merges two
exercises into a single file, so the mapping is one file → many exercise keys.

Tracks are re-encoded to **48 kbps mono** (ffmpeg 9.0, installed via
`winget install Gyan.FFmpeg`). That took the full set from 160 MB to 75 MB.
The CD rips were around 100 kbps to begin with, so the saving is a little over
2×, not the 8× a 128 kbps stereo source would have given.

Pictures are cut to PNG and then, when ffmpeg is present, also to JPEG at
`-q:v 3`; `crop.mjs` keeps whichever file came out smaller and `build.mjs`
embeds it with the matching MIME type. Every crop in Units 1–2 chose JPEG, and
the two worksheets went from 3.9 MB and 3.3 MB of pictures to 851 kB and
681 kB. Text panels were checked by eye afterwards — the titles box and the
alphabet strip are still crisp at that quality.

Net effect: Unit 1 went 21.3 → **8.6 MB**, Unit 2 13.6 → **5.4 MB**. The whole
book should land near 110 MB rather than 250 MB.

## Where the answers come from

Every Unit 1 key was read out of the **teacher's edition**, which unlike the
student scans has a text layer: Ex 3A, Ex 5 (Cate, Erick, Sophia, Zachary),
Ex 6B (Mr. Santos, Mrs. Wilson, Miss Park, Ms. Rossi), Ex 9A, Ex 9B, and Ex 12.
The Ex 5 and Ex 12 listening scripts are reproduced in collapsible panels.

**One exception, flagged deliberately.** The teacher's PDF on this machine does
not include the Grammar plus answer key, so the 17 items on p. 132 were derived
rather than copied: GP 1 is forced by the his/her rule and by who is speaking;
GP 2 is pinned by its own closed word bank of nine items, each used exactly
once. Both are sound, but they are the only answers in the project not read
from a printed key.

Where the book accepts two answers, the file marks one and says so in the
reveal — Ex 9B *Hi, ______ Cara Ruiz.* asks for *My name is* and notes that
*I'm* is also correct. The same applies to Unit 10 Ex 3A, where the key itself
prints two options (*What time/When*, *What sports/What*); both are accepted.

**Unit 10 is fully keyed.** Every exercise that scores — the Snapshot (printed
upside down on p. 64), Ex 3A and 3B, the Ex 4 and Ex 9 listenings, Ex 7A, the
Word Power map and the reading — comes from the teacher's edition. Ex 7B is the
page-67 pair work written out; its four short answers follow mechanically from
the Ex 7A key and nothing else, so it is derived in the same weak sense as a
restated sentence, not guessed.

## Publishing

The content is Cambridge University Press material. Published the same way as
the Mindset worksheet: its own public repo, separate from the main site, with
`robots.txt` (`Disallow: /`) and a `noindex` meta tag in every page — reachable
by link, not by search.

Source PDFs and CDs are course material and are not committed. **`_source/audio/`
is also excluded** (see `.gitignore`): the tracks are already embedded in every
worksheet, so publishing 184 individually downloadable Cambridge MP3s would add
nothing for the learner. The consequence is that a fresh clone cannot re-run
`build.mjs` until the discs are re-imported:

```bash
node _source/import-audio.mjs      # needs the CDs; restores _source/audio/
```
